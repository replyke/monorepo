---
title: "Get Connections Count"
api: "GET /v7/:projectId/users/:userId/connections-count"
description: "Get the number of accepted connections for a user"
---

Returns the total number of accepted connections for the specified user. Authentication is optional — the endpoint works without a token. When the caller is signed in, any user with a block between them and the caller, in either direction, is excluded from the count. Block filtering requires the `moderation` bundle.

## Path Parameters

<ParamField path="userId" type="string" required>
  The Sublay user ID (UUID) of the user whose connection count to retrieve.
</ParamField>

## Response

On success, returns HTTP `200`:

<ResponseField name="count" type="number">
  Total number of accepted connections for this user.
</ResponseField>
