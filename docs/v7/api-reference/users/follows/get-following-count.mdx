---
title: "Get Following Count"
api: "GET /v7/:projectId/users/:userId/following-count"
description: "Get the number of users that a specific user follows"
---

Returns the total number of users that the specified user follows. Authentication is optional. The endpoint works without a token, but when the caller is signed in, users they have blocked are excluded from the count.

## Path Parameters

<ParamField path="userId" type="string" required>
  The Sublay user ID (UUID) of the user whose following count to retrieve.
</ParamField>

## Response

On success, returns HTTP `200`:

<ResponseField name="count" type="number">
  Total number of users this user is following.
</ResponseField>
