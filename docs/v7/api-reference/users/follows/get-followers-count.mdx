---
title: "Get Followers Count"
api: "GET /v7/:projectId/users/:userId/followers-count"
description: "Get the number of followers for a specific user"
---

Returns the total number of users following the specified user. Authentication is optional. The endpoint works without a token, but when the caller is signed in, users they have blocked are excluded from the count.

## Path Parameters

<ParamField path="userId" type="string" required>
  The Sublay user ID (UUID) of the user whose follower count to retrieve.
</ParamField>

## Response

On success, returns HTTP `200`:

<ResponseField name="count" type="number">
  Total number of users following this user.
</ResponseField>
