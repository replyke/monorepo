---
title: "Revoke Invite"
api: "POST /v7/:projectId/workspaces/:id/invites/:inviteId/revoke"
description: "Revoke a pending invitation"
---

Marks a pending invitation `revoked`. Requires the `invite` capability (or owner). Fires `workspace.invite.revoked`.

## Path Parameters

<ParamField path="id" type="string" required>
  The workspace UUID.
</ParamField>

<ParamField path="inviteId" type="string" required>
  The invitation UUID.
</ParamField>

## Body Parameters

<ParamField body="actingUserId" type="string">
  Service/master keys only — the user to act as. Enforced: the `invite` capability (or ownership) is required *of the named user*. Omit it to act as the app itself (unbounded). See [Acting on behalf of a user](/sdk/workspaces/overview#acting-on-behalf-of-a-user).
</ParamField>

## Response

```json
{ "success": true }
```

## Error Responses

<AccordionGroup>
  <Accordion title="Invite Not Found — 404">
    ```json
    { "error": "Invitation not found.", "code": "workspace/invite-not-found" }
    ```
  </Accordion>
</AccordionGroup>
