---
title: "Flip Inherit Flag"
api: "PATCH /v7/:projectId/workspaces/:id/inherit-flag"
description: "Owner-only flip of the reach/inherit flag"
---

Flips the workspace's `inheritsFromParent` flag — the switch controlling whether authority from above reaches into this node. See [Reach & the wall/door rule](/data-models/workspace#reach-and-the-wall-door-rule).

- **Owner-only in both directions** (the workspace's own owner or an ancestor owner). **Not a capability.**
- Subject to the **enforced-default lock**: if the project sets [`workspaces.inheritEnforced`](/sdk/workspaces/overview#project-settings), the flip is rejected with `403 workspace/inherit-enforced`.

## Path Parameters

<ParamField path="id" type="string" required>
  The workspace UUID.
</ParamField>

## Body Parameters

<ParamField body="inheritsFromParent" type="boolean" required>
  The new flag value (`true` = open/door, `false` = sealed/wall).
</ParamField>

<ParamField body="actingUserId" type="string">
  Service/master keys only — the user to act as. **Not enforced on this endpoint yet** (see the warning below).
</ParamField>

<Warning>
  **`actingUserId` is not enforced on this endpoint yet.** The guard on this route resolves authority *after* the master/service-key bypass, so for a key the named user is never looked up. The call runs with **full owner authority regardless of who you name** — including a user with no standing on this workspace at all. Naming a non-owner will **not** stop the call. The value is **discarded entirely** — it is not read, not stored, and not carried on any webhook, so it is not an audit trail either. Gate the call in your own backend. Enforcement — binding a key to the named user's real authority — lands in a follow-up change. (The `workspace/inherit-enforced` project lock is a separate gate and **does** still apply.)
</Warning>

## Response

Returns the updated [Workspace](/data-models/workspace) object.

## Error Responses

<AccordionGroup>
  <Accordion title="Unauthorized — 403">
    ```json
    { "error": "Only the owner or an ancestor owner may flip the inherit flag.", "code": "workspace/unauthorized" }
    ```
  </Accordion>
  <Accordion title="Inherit Enforced — 403">
    ```json
    { "error": "The project enforces its inherit default; the flag cannot be changed.", "code": "workspace/inherit-enforced" }
    ```
  </Accordion>
</AccordionGroup>
