<Note>
  **Requires the `entities` bundle.** A project without the entities bundle returns `403 database/tables-not-available` for entity calls. See [Bundles](/bundles).
</Note>

Entities are the central content objects in Sublay — posts, articles, products, or any item in your application that users interact with. The `entities` module gives you full control over their lifecycle, reactions, and drafts. All actions are performed on behalf of the logged-in user.

---

### createEntity

Creates a new entity, optionally as a draft or without attributing it to the logged-in user.

```typescript
const entity = await sublay.entities.createEntity({
  foreignId: "post-42",
  title: "My First Post",
  content: "Hello world",
  keywords: ["intro", "welcome"],
  metadata: { category: "blog" },
});
```

<ParamField body="foreignId" type="string">
  Your application's identifier for this entity. Used for idempotent lookups via `fetchEntityByForeignId`.
</ParamField>

<ParamField body="sourceId" type="string">
  An optional secondary identifier for grouping or filtering entities.
</ParamField>

<ParamField body="spaceId" type="string">
  The space this entity belongs to.
</ParamField>

<ParamField body="title" type="string">
  Title text for the entity.
</ParamField>

<ParamField body="content" type="string">
  Body/content text for the entity.
</ParamField>

<ParamField body="attachments" type="Record<string, any>[]">
  File or media attachments.
</ParamField>

<ParamField body="keywords" type="string[]">
  Tags or keywords used for filtering and discovery.
</ParamField>

<ParamField body="mentions" type="Mention[]">
  User mentions embedded in the entity.
</ParamField>

<ParamField body="location" type="object">
  Geographic coordinates `{ latitude: number; longitude: number }`.
</ParamField>

<ParamField body="metadata" type="Record<string, any>">
  Arbitrary public metadata.
</ParamField>

<ParamField body="nsfw" type="boolean">
  The entity's own NSFW flag. Defaults to `false`. Effective NSFW also inherits from the entity's space. See [Entity NSFW flagging](/data-models/entity#nsfw-flagging).
</ParamField>

<ParamField body="isDraft" type="boolean">
  When `true`, the entity is created as an unpublished draft.
</ParamField>

<ParamField body="excludeUserId" type="boolean">
  When `true`, creates the entity without attributing it to the logged-in user (authorless).
</ParamField>

**Returns** — `Promise<Entity>`

### fetchEntityByForeignId

Fetches an entity by your application's own identifier. Optionally creates it if not found.

```typescript

```

<ParamField body="foreignId" type="string" required>

</ParamField>

<ParamField body="createIfNotFound" type="boolean">

</ParamField>

<ParamField body="include" type="string">
  Comma-separated list of associations to populate.

### fetchManyEntities

Fetches a filtered, paginated list of entities (feeds). Supports rich filtering by metadata, keywords, location, and more.

```typescript
const { data, pagination } = await sublay.entities.fetchManyEntities({
  spaceId: "spc_abc123",
  sortBy: "hot",
  page: 1,
  limit: 20,
  metadataFilters: { includes: { category: "blog" } },
});
```

<ParamField body="sourceId" type="string">
  Filter by source ID.
</ParamField>

<ParamField body="spaceId" type="string">
  Filter to entities within a specific space.
</ParamField>

<ParamField body="sortBy" type="string">
  Sort order: `"createdAt"` (chronological — honors `sortDir`), `"hot"` (trending), `"top"` (highest scored), or `"controversial"`. A `"metadata.<prop>"` value is also accepted to sort by a metadata field.
</ParamField>

<ParamField body="sortDir" type="string">
  Sort direction: `"asc"` or `"desc"`.
</ParamField>

<ParamField body="sortType" type="string">
  How to interpret a metadata sort value: `"auto"`, `"numeric"`, `"text"`, `"boolean"`, or `"timestamp"`.
</ParamField>

<ParamField body="sortByReaction" type="string">
  Sort by the count of a specific reaction: `"upvote"`, `"downvote"`, `"like"`, `"love"`, `"wow"`, `"sad"`, `"angry"`, or `"funny"`.
</ParamField>

<ParamField body="page" type="number">
  Page number (1-indexed).
</ParamField>

<ParamField body="limit" type="number">
  Results per page.
</ParamField>

<ParamField body="include" type="string">
  Comma-separated list of associations to populate (e.g. `"user"`).
</ParamField>

<ParamField body="timeFrame" type="string">
  Time window to restrict results to: `"hour"`, `"day"`, `"week"`, `"month"`, or `"year"`.
</ParamField>

<ParamField body="userId" type="string">
  The author to filter by, also used as the viewing user to resolve `followedOnly`.
</ParamField>

<ParamField body="followedOnly" type='"true" | "false"'>
  When `"true"`, returns only entities from users the given `userId` follows.
</ParamField>

<ParamField body="keywordsFilters" type="object">
  Filter by keyword tags: `{ includes?: string[]; doesNotInclude?: string[] }`.
</ParamField>

<ParamField body="metadataFilters" type="object">
  Filter by metadata fields: `{ includes?: object; includesAny?: object[]; doesNotInclude?: object; exists?: string[]; doesNotExist?: string[] }`.
</ParamField>

<ParamField body="titleFilters" type="object">
  Filter by title: `{ hasTitle?: "true" | "false"; includes?: string | string[]; doesNotInclude?: string | string[] }`.
</ParamField>

<ParamField body="contentFilters" type="object">
  Filter by content: `{ hasContent?: "true" | "false"; includes?: string | string[]; doesNotInclude?: string | string[] }`.
</ParamField>

<ParamField body="attachmentsFilters" type="object">
  Filter by attachments: `{ hasAttachments?: "true" | "false" }`.
</ParamField>

<ParamField body="locationFilters" type="object">
  Filter within a geographic radius: `{ latitude: string; longitude: string; radius: string }`.
</ParamField>

<ParamField body="nsfwFilter" type='"include-all" | "exclude" | "only"'>
  Filter by effective NSFW (`entity.nsfw OR its space's nsfwEffective`). `"include-all"` (default) adds no predicate; `"exclude"` drops effective-NSFW entities; `"only"` returns only them. See [Entity NSFW flagging](/data-models/entity#nsfw-flagging).
</ParamField>

<ParamField body="blockedFilter" type='"exclude" | "include-outbound-blocked"'>
  How to treat entities authored by users the viewer is [block-edged](/sdk/moderation/overview#blocking) with. `"exclude"` (default) hides them; `"include-outbound-blocked"` re-includes only the viewer's own outbound-blocked authors — never content from users who blocked the viewer. No effect without the `moderation` bundle.
</ParamField>

<SpaceReputationParams variant="context" field="body" />

**Returns** — `Promise<PaginatedResponse<Entity>>`

### updateEntity

Updates fields on an existing entity.

```typescript
const entity = await sublay.entities.updateEntity({
  entityId: "ent_xyz789",
  title: "Updated Title",
  metadata: { featured: true },
});
```

<ParamField body="entityId" type="string" required>
  The Sublay entity ID to update.
</ParamField>

<ParamField body="title" type="string">
  New title.
</ParamField>

<ParamField body="content" type="string">
  New content body.
</ParamField>

<ParamField body="attachments" type="Record<string, any>[]">
  Updated attachments list.
</ParamField>

<ParamField body="keywords" type="string[]">
  Updated keywords list.
</ParamField>

<ParamField body="mentions" type="Mention[]">
  Updated user mentions list.
</ParamField>

<ParamField body="location" type="object">
  Updated coordinates `{ latitude: number; longitude: number }`.
</ParamField>

<ParamField body="metadata" type="Record<string, any>">
  Updated metadata. Merged with existing values.
</ParamField>

<ParamField body="nsfw" type="boolean">
  Updated NSFW own-flag. A space moderator flagging another user's entity uses `spaces.setSpaceEntityNsfw` instead. See [Entity NSFW flagging](/data-models/entity#nsfw-flagging).
</ParamField>

**Returns** — `Promise<Entity>`

```typescript

  entityId: "ent_xyz789",

});
```

<ParamField body="entityId" type="string" required>

</ParamField>

<ParamField body="reactionType" type="ReactionType" required>

### getUserReaction

Gets the logged-in user's reaction on an entity. Returns `null` if there is no reaction.

```typescript
const { reactionType } = await sublay.entities.getUserReaction({
  entityId: "ent_xyz789",
});
// reactionType is "like" | "upvote" | ... | null
```

<ParamField body="entityId" type="string" required>
  The Sublay entity ID.
</ParamField>

**Returns** — `Promise<{ reactionType: ReactionType | null }>`


<ParamField body="entityId" type="string" required>
  The Sublay entity ID.
</ParamField>

**Returns** — `Promise<{ saved: boolean; collections: { id: string; name: string }[] }>`
